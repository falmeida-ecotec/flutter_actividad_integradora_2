# 📱 Flutter - Registro de Usuario con SQLite

## 📌 Descripción
Aplicación móvil desarrollada en Flutter que permite registrar información básica de un usuario mediante un formulario validado, almacenar los datos localmente usando SQLite y visualizar la información en una pantalla tipo perfil.

Este proyecto fue desarrollado como actividad integradora, aplicando conceptos de validación de formularios, persistencia de datos y diseño de interfaces.

---

## 🚀 Tecnologías utilizadas
- Flutter
- Dart
- SQLite (sqflite)
- Material Design

---

## 🗄️ Uso de SQLite
Se implementa una base de datos local (`usuarios.db`) para almacenar la información ingresada por el usuario.

Funciones principales:
- Creación de tabla `usuarios`
- Inserción de datos
- Consulta del último usuario registrado
- Persistencia de datos tras cerrar la app

---

## ⚙️ Funcionalidades
- ✔ Registro de usuario con validaciones
- ✔ Validación con `Form` y `GlobalKey`
- ✔ Navegación entre pantallas
- ✔ Envío de datos entre widgets
- ✔ Persistencia con SQLite
- ✔ Consulta del último usuario guardado
- ✔ UI con `Card` y `CircleAvatar`
- ✔ Widgets reutilizables
- ✔ Ícono personalizado de la app
